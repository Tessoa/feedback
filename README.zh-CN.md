# Tessoa 反馈

[English](README.md) · **简体中文**

**[tessoa](https://tessoa.com) 是一个用 Rust 编写、由 GPU 绘制界面的文件管理器**，Windows、macOS 与 Linux 均有官方构建。到[官网](https://tessoa.com)下载，到[说明文档](https://docs.tessoa.com/)上手。

## 关于这个仓库

**这里只放反馈，不放代码。** Bug 与功能建议走 [Issue](https://github.com/Tessoa/feedback/issues)，在这里收集、归类，并进入版本计划；使用问题与还没成形的设想走 [Discussions](https://github.com/Tessoa/feedback/discussions)。

## 提交反馈

从[新建 Issue](https://github.com/Tessoa/feedback/issues/new/choose) 开始，选一个最接近的类型：

- **🐞 Bug 反馈** —— 崩溃、报错、显示错乱、行为与预期不符。版本号、操作系统与复现步骤是必填项：缺了它们，问题基本无从查起。能附上截图或十几秒的录屏最好。
- **✨ 功能建议** —— 先讲你卡在什么问题上，再讲你想要什么。知道了问题本身，我们有时能给出比你设想中更顺手的解法。

选错类型不要紧，我们会帮你改。

## 提问与讨论

[Discussions](https://github.com/Tessoa/feedback/discussions) 用来放 Issue 装不下的事：

- **🙏 [使用问题](https://github.com/Tessoa/feedback/discussions/new?category=q-a)** —— 功能藏在哪、某个设置管什么、文档没写清楚。答案会留在原帖里，后来的人搜得到；这类提问同时也在告诉我们文档差在哪。
- **💡 [设想](https://github.com/Tessoa/feedback/discussions/new?category=ideas)** —— 想法还没成形，或者你自己也拿不准该不该做，先放这里聊。聊清楚了再转成功能建议。
- **🗳️ 投票** —— 有些取舍我们自己拿不准，会开投票。你投的一票会影响做不做、先做哪个。
- **📣 公告** —— 发版与变更由我们发布，欢迎在下面接着聊。

## 提交之前

先搜一遍[已有 Issue](https://github.com/Tessoa/feedback/issues?q=is%3Aissue)（包括已关闭的）和[已有讨论](https://github.com/Tessoa/feedback/discussions)。同一个问题已经有人提过的话，去那条下面 👍 或补充你的复现环境，比新开一条更快被看到。

版本号在命令面板的「关于 → 版本」里。反馈用中文或 English 都行，日本語・Deutsch も歓迎です。

## 请不要在这里提交

**安全漏洞**请勿公开提交 Issue 或讨论，先私下联系维护者，等修复发布后我们再公开致谢。

Issue 与讨论对所有人可见，因此也请不要贴出**许可证码、账号密码、支付凭证**，日志或截图里的真实姓名、公司路径也请先打码。
