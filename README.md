# Tessoa Feedback

**English** · [简体中文](README.zh-CN.md)

**[tessoa](https://tessoa.com) is a GPU-accelerated file manager written in Rust**, with official builds for Windows, macOS and Linux. See the [website](https://tessoa.com) to download it and the [documentation](https://docs.tessoa.com/) to learn it.

## About this repository

This repository holds **issues only — no source code**. It is where bug reports and feature requests for tessoa are collected, triaged and turned into release plans.

## Filing an issue

Start from [New issue](https://github.com/Tessoa/feedback/issues/new/choose) and pick the closest type:

- **🐞 Bug report** — crashes, errors, visual glitches, anything not behaving as expected. Version, OS and steps to reproduce are required: without them a bug is rarely traceable. Screenshots or a short screen recording help a lot.
- **✨ Feature request** — tell us the problem you ran into before the solution you have in mind. Knowing the problem, we can sometimes offer a better answer than the one you asked for.
- **💬 Question** — where a feature lives, what a setting does, anything the docs left unclear. These also tell us where the docs fall short.

Picking the wrong type is fine, we will sort it out.

## Before you post

[Search the existing issues](https://github.com/Tessoa/feedback/issues?q=is%3Aissue) first, closed ones included. If your problem is already reported, a 👍 or an extra reproduction detail on that thread gets attention faster than a new one.

Your version number is in the command palette under *About → Version*. Write in English or 中文, 日本語・Deutsch も歓迎です。

## Please don't post here

Report **security vulnerabilities privately** to the maintainers instead of opening an issue; we will credit you publicly once a fix ships.

Issues are visible to everyone, so keep **license keys, passwords and payment details** out of them, and mask real names or company paths in logs and screenshots.
