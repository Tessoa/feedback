# Tessoa Feedback

**English** · [简体中文](README.zh-CN.md)

**[tessoa](https://tessoa.com) is a GPU-accelerated file manager written in Rust**, with official builds for Windows, macOS and Linux. See the [website](https://tessoa.com) to download it and the [documentation](https://docs.tessoa.com/) to learn it.

## About this repository

This repository holds **feedback only — no source code**. Bugs and feature requests go to [Issues](https://github.com/Tessoa/feedback/issues), where they are collected, triaged and turned into release plans; questions and half-formed ideas go to [Discussions](https://github.com/Tessoa/feedback/discussions).

## Filing an issue

Start from [New issue](https://github.com/Tessoa/feedback/issues/new/choose) and pick the closest type:

- **🐞 Bug report** — crashes, errors, visual glitches, anything not behaving as expected. Version, OS and steps to reproduce are required: without them a bug is rarely traceable. Screenshots or a short screen recording help a lot.
- **✨ Feature request** — tell us the problem you ran into before the solution you have in mind. Knowing the problem, we can sometimes offer a better answer than the one you asked for.

Picking the wrong type is fine, we will sort it out.

## Asking and discussing

[Discussions](https://github.com/Tessoa/feedback/discussions) is for what an issue does not hold:

- **🙏 [Q&A](https://github.com/Tessoa/feedback/discussions/new?category=q-a)** — where a feature lives, what a setting does, anything the docs left unclear. The answer stays on the thread for whoever searches for it next, and the question itself tells us where the docs fall short.
- **💡 [Ideas](https://github.com/Tessoa/feedback/discussions/new?category=ideas)** — for a thought that has not taken shape yet, or one you are not sure should be built at all. Talk it over first; we can turn it into a feature request later.
- **🗳️ Polls** — some trade-offs we cannot call on our own, so we put them to a vote. Your vote affects what gets built, and in what order.
- **📣 Announcements** — releases and changes, posted by us. Comments welcome.

## Before you post

Search the [existing issues](https://github.com/Tessoa/feedback/issues?q=is%3Aissue) first, closed ones included, and the [existing discussions](https://github.com/Tessoa/feedback/discussions). If your problem is already reported, a 👍 or an extra reproduction detail on that thread gets attention faster than a new one.

Your version number is in the command palette under *About → Version*. Write in English or 中文, 日本語・Deutsch も歓迎です。

## Please don't post here

Report **security vulnerabilities privately** to the maintainers instead of opening an issue or a discussion; we will credit you publicly once a fix ships.

Issues and discussions are visible to everyone, so keep **license keys, passwords and payment details** out of them, and mask real names or company paths in logs and screenshots.
